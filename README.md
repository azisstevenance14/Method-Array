# 🚀 JavaScript ES6+ Array Methods & Fetch API Curriculum

Repitori ini berisi kumpulan project latihan praktis untuk mendalami konsep modern **JavaScript (ES6+)**, manipulasi *Array* fungsional, penanganan data asinkron (*Async/Await*), serta integrasi data lokal menggunakan *Fetch API*.

---

## 📂 Struktur Project

Project ini disusun secara modular dengan struktur 3 file (`index.html`, `script.js`, `data.json`) di setiap foldernya:

- **`01-foreach/`** — Eksplorasi perulangan prosedural untuk aksi langsung (*side effects*) dan manipulasi DOM.
- **`02-map/`** — Transformasi data menggunakan `.map()` dikombinasikan dengan `.join('')` untuk *rendering* HTML yang bersih.
- **`03-filter/`** — Menyaring data secara spesifik berdasarkan kondisi tertentu menggunakan `.filter()`.
- **`04-reduce/`** — Merangkum dan mengakumulasi data menjadi nilai tunggal menggunakan `.reduce()`.

---

## 🧠 Konsep Utama yang Dipelajari

1. **Modern ES6+ Syntax**: Penggunaan *Arrow Functions* (`=>`), *Template Literals* (`` `${}` ``), dan deklarasi variabel modern (`const`).
2. **Asynchronous JavaScript**: Memanfaatkan `async` dan `await` untuk menangani proses permintaan data eksternal (*Fetch API*) secara aman dan terstruktur.
3. **Array Transformation vs Procedural**: 
   - `.forEach()` untuk eksekusi aksi.
   - `.map()` untuk transformasi array.
   - `.filter()` untuk penyaringan data.
   - `.reduce()` untuk agregasi data statistik.
4. **DOM Manipulation**: Mencegah duplikasi elemen dengan `innerHTML = ''` dan merender data ke antarmuka pengguna secara dinamis.

## 🛠️ Cara Menjalankan Project

1. Pastikan kamu sudah menginstal ekstensi **Live Server** di VS Code.
2. Clone atau unduh repitori ini ke komputermu.
3. Buka salah satu folder latihan (misal: `02-map`).
4. Klik kanan pada file `index.html`, lalu pilih **"Open with Live Server"**.
5. Klik tombol interaktif pada halaman web untuk melihat hasil eksekusi script JavaScript di balik layar!
